# PDF y Word Fácil

App de escritorio, de código abierto (MIT), sin anuncios y sin internet.

- **Word a PDF:** usa LibreOffice si lo tienes instalado (mejor calidad). Si no, usa un motor básico incluido (solo .docx).
- **PDF a Word:** extrae el texto y los títulos. En páginas escaneadas usa OCR (español e inglés incluidos).

Desarrollo: `npm install` y luego `npm start`. Para crear el .exe: `npm run build`.
